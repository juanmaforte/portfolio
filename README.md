PORTFOLIO - JUAN MANUEL FORTE
El sitio está pensado como una carta de presentación visual, donde se reúnen algunos de mis trabajos 
realizados durante la carrera y aplicando los conocimientos adquiridos en la materia de HTML y CSS.

------ Estructura del sitio ------
El portfolio está dividido en cuatro secciones principales:
• Inicio: presentación personal en un splash de bienvenida y enlace a las otras páginas
• Mi CV: información general sobre mi recorrido profesional y mis intereses.
• Trabajos: muestra de proyectos académicos y personales.
• Contacto: formulario de contacto con campos básicos.
Además, el sitio incluye un elemento multimedia (audio) embebido y galerías de imágenes para cada proyecto.

------ Tecnologías utilizadas ------ 
• HTML para la estructura del sitio.
• CSS para el diseño visual y animaciones.
• Flexbox para la disposición de los elementos.
• Media queries para la adaptación a distintos tamaños de pantalla.
• Tipografía principal: Sofia Sans.
• Tipografía para títulos: Viga.

------ Diseño responsive ------ 
El sitio está preparado para visualizarse correctamente en diferentes dispositivos:
• Móviles: hasta 750px
• Tablets: de 751px a 1150px
• Desktop: más de 1150px
